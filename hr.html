One week at a time, exactly like your paper sheet: change a number to correct it, type into an empty cell to add a missing day, clear a cell to delete that day (it asks first). Nothing is written while you type: every changed cell just turns yellow. When you are done, ONE press of SAVE CHANGES writes everything in a single fast call (deletions are counted and confirmed at that point). Grey H / OFF / S marks work the same way and stay in sync with the Holidays calendar: type H, S or O into an empty cell to set one, retype to change it, clear the cell to remove it. Typing hours over a mark saves the hours and removes the mark; typing a mark over hours asks first, then replaces the logged hours with the mark. A cell showing 2 rows holds more than one logged entry for that person on that day — open View Entries to sort it out.

Manual Entry — missed banking days only

Take-in normally arrives automatically from LPA Banking. Use this ONLY when a day failed to arrive (like 30-09-2026): copy the SAME four figures from LPA Banking. One press fills all three ledgers — Take-in, the tip pool (Cash Tips) and the Cash List (Cash In Hand). Each piece is written only if the day doesn't already have it: anything already there is left untouched and its existing figures are shown, so pressing SAVE twice (or Streamlit retrying later) can never create doubles. Leave a figure 0/empty to skip that piece.
